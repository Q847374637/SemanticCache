# SemanticCache.Core

A high-performance semantic caching library for .NET designed for RAG systems and LLM integrations. It provides extremely fast local memory searches for similar queries to reduce LLM API costs and latency.

## Features
* Hardware-accelerated cosine similarity math using SIMD
* Thread-safe concurrent access for web APIs
* Strict memory footprint control via LRU eviction

For full documentation, benchmarks, and dependency injection examples, please visit the [Official GitHub Repository](https://github.com/Q847374637/SemanticCache).
